MetaAOT

MSc in Cloud Computing Research Project — National College of Ireland
Research Objective

A static build-time analyzer that evaluates how well a Maven dependency tree is prepared for Ahead-of-Time native compilation, intercepting potential architectural gaps before any code execution or compilation begins.

Layered Evidence Model
  • (i) Embedded Metadata: Inspecting native-image configurations inside JAR manifests.
  • (ii) External Reachability: Validating artifacts against target open-source AOT community specifications.
  • (iii) Conservative Baseline: Applying risk-mitigated classification when explicit evidence is absent.

Disclaimer: This is an independent academic tool developed purely for validation of research objectives.
