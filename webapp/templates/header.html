MetaAOT

MSc in Cloud Computing Research Project — National College of Ireland
Research Objective

A static build-time analyzer that evaluates how well a Maven dependency tree is prepared for Ahead-of-Time native compilation, intercepting potential architectural gaps before any code execution or compilation begins.

Multi-Layer AOT Evidence Model
Layer 1: Local Manifest Inspection
Scans in-memory JAR bytecode and META-INF/native-image/ configurations.
Layer 2: External Reachability Index
Evaluates exact versions and semantic proximity against AOT community specifications.
Layer 3: Transitive Graph Fallback
Traverses dependency subgraphs to resolve implicit support before marking missing evidence.
View Detailed Status Classification Mapping
Direct Verification Statuses:
  • EMBEDDED_METADATA: Native spec embedded inside JAR.
  • OFFICIAL_METADATA: Perfect coordinate/version match in registry.
  • NOT_APPLICABLE: No bytecode or explicitly flagged as non-native.
Approximated & Fallback Statuses:
  • VERSION_NOT_TESTED: Recognized family, semantic version proximity fallback.
  • INDIRECT_EVIDENCE_ONLY: Implicit support found via subgraph traversal.
  • EVIDENCE_NOT_FOUND: Residual fallback (no footprint across all layers).
